## About Dataset

This dataset provides detailed information about the occupational composition of an industry for a specific combination of class of worker, industry, geographic area, and year.

It enables labor market analysis by showing how occupations distributed across industries and regions and helps organizations, researchers, and policymakers understand workforce structure, identity employment trends, and project future occupational demand.

The dataset reflects the latest available data from Labor Force Survey (LFS) and Canadian Occupational Projection System (COPS)

## Use Cases

* Analyze Workforce distribution across industries.
* Identify Key Industries employing specific occupations.
* Evaluate how occupational demand changes over time.

## Details

* Total Records: 500K
* Dataset Size:  1 GB
* Format: CSV, Json
* Time Frame: 2001 to current occupational year
* Update Frequency: Quarterly
* Current Version: 2025.1
* Geographic Coverage: Canada (Nation, Provinces, and Economic Regions)
* Language: English
